# 10 — Full Pipeline Project

> This is the capstone. All tools wired together, end-to-end.
> Do this only after completing tools 01–09 individually.

## What You Are Building

A production-style CI/CD pipeline for a Java Spring Boot application. Every tool from tools 01–09 is active in this pipeline. By the end, you will have:

- A running SonarQube + Nexus + Jenkins stack (Docker Compose)
- A sample app repo (app code + Dockerfile + Terraform)
- A GitOps repo (K8s manifests + Kyverno policies)
- A complete Jenkinsfile that runs all stages end-to-end
- ArgoCD watching the GitOps repo and deploying to K8s
- Vault injecting secrets into the running pod
- Slack notifications on build status changes

## The Sample App

Use this minimal Spring Boot app, or substitute any app you have.

**pom.xml** (key sections):
```xml
<!-- Generated by GitHub Copilot -->
<properties>
    <sonar.projectKey>sample-app</sonar.projectKey>
    <sonar.host.url>${env.SONAR_HOST_URL}</sonar.host.url>
</properties>
```

**Dockerfile:**
```dockerfile
# Generated by GitHub Copilot
FROM eclipse-temurin:17-jre-alpine

# Run as non-root — required by Kyverno policy block-root-containers
RUN addgroup -S app && adduser -S app -G app
USER app

WORKDIR /app
COPY --chown=app:app target/*.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java", "-jar", "app.jar"]
```

**K8s Deployment (in GitOps repo):**
```yaml
# Generated by GitHub Copilot
apiVersion: apps/v1
kind: Deployment
metadata:
  name: sample-app
  namespace: default
spec:
  replicas: 1
  selector:
    matchLabels:
      app: sample-app
  template:
    metadata:
      labels:
        app: sample-app
      annotations:
        vault.hashicorp.com/agent-inject: "true"
        vault.hashicorp.com/role: "sample-app"
        vault.hashicorp.com/agent-inject-secret-config.properties: "secret/data/sample-app/config"
    spec:
      serviceAccountName: sample-app-sa
      containers:
        - name: app
          image: nexus:8082/sample-app:1          # Jenkins updates this line
          resources:
            requests:
              cpu: "100m"
              memory: "256Mi"
            limits:
              cpu: "500m"
              memory: "512Mi"
          securityContext:
            runAsNonRoot: true                    # Required by Kyverno policy
            readOnlyRootFilesystem: true
          ports:
            - containerPort: 8080
```

## The Complete Jenkinsfile

```groovy
// Generated by GitHub Copilot
pipeline {
    agent any

    tools {
        // must match name in Manage Jenkins → Tools → Maven installations
        maven 'maven'
    }

    environment {
        NEXUS_REGISTRY  = 'nexus:8082'
        IMAGE_NAME      = "${NEXUS_REGISTRY}/sample-app"
        IMAGE_TAG       = "${env.BUILD_NUMBER}"
        SONAR_PROJECT   = 'sample-app'
        GITOPS_REPO     = 'https://github.com/your-org/gitops-repo.git'
    }

    stages {

        stage('Checkout') {
            steps {
                git branch: 'main',
                    url: 'https://github.com/your-org/sample-app.git',
                    credentialsId: 'github-credentials'
            }
        }

        stage('Checkov — IaC Scan') {
            steps {
                sh '''
                    checkov -d terraform/ \
                      --framework terraform \
                      --compact \
                      --soft-fail
                '''
            }
        }

        stage('Build') {
            steps {
                // verify (not package) — compiles classes into target/classes, which Sonar's Java analyzer requires
                sh 'mvn clean verify -DskipTests'
            }
        }

        stage('SonarQube Analysis') {
            steps {
                withSonarQubeEnv('SonarQube') {
                    // fully qualified plugin — avoids "No plugin found for prefix 'sonar'" on restricted agents
                    sh "mvn org.sonarsource.scanner.maven:sonar-maven-plugin:sonar -Dsonar.projectKey=${SONAR_PROJECT}"
                }
            }
        }

        stage('Quality Gate') {
            steps {
                timeout(time: 5, unit: 'MINUTES') {
                    waitForQualityGate abortPipeline: true
                }
            }
        }

        stage('OWASP Dependency Check') {
            steps {
                dependencyCheck additionalArguments: '--scan ./ --format XML --format HTML',
                                odcInstallation: 'Dependency-Check'
                dependencyCheckPublisher pattern: 'dependency-check-report.xml',
                                         failedTotalCritical: 1
            }
        }

        stage('Docker Build') {
            steps {
                sh "docker build -t ${IMAGE_NAME}:${IMAGE_TAG} ."
            }
        }

        stage('Trivy — Image Scan') {
            steps {
                sh """
                    trivy image \
                      --exit-code 1 \
                      --severity HIGH,CRITICAL \
                      --ignore-unfixed \
                      --format table \
                      ${IMAGE_NAME}:${IMAGE_TAG}
                """
            }
            post {
                always {
                    sh """
                        trivy image \
                          --exit-code 0 \
                          --format json \
                          --output trivy-report.json \
                          ${IMAGE_NAME}:${IMAGE_TAG}
                    """
                    archiveArtifacts artifacts: 'trivy-report.json', allowEmptyArchive: true
                }
            }
        }

        stage('Push to Nexus') {
            steps {
                script {
                    docker.withRegistry("http://${NEXUS_REGISTRY}", 'nexus-credentials') {
                        docker.image("${IMAGE_NAME}:${IMAGE_TAG}").push()
                        docker.image("${IMAGE_NAME}:${IMAGE_TAG}").push('latest')
                    }
                }
            }
        }

        stage('Cosign — Sign Image') {
            steps {
                withCredentials([
                    file(credentialsId: 'cosign-private-key', variable: 'COSIGN_KEY'),
                    string(credentialsId: 'cosign-key-password', variable: 'COSIGN_PASSWORD')
                ]) {
                    sh """
                        COSIGN_PASSWORD=${COSIGN_PASSWORD} \
                        cosign sign --key ${COSIGN_KEY} --yes \
                          --allow-insecure-registry \
                          ${IMAGE_NAME}:${IMAGE_TAG}
                    """
                }
            }
        }

        stage('Update GitOps Repo') {
            steps {
                withCredentials([usernamePassword(credentialsId: 'github-credentials',
                                                   usernameVariable: 'GIT_USER',
                                                   passwordVariable: 'GIT_TOKEN')]) {
                    sh """
                        rm -rf gitops-repo
                        git clone https://${GIT_USER}:${GIT_TOKEN}@github.com/your-org/gitops-repo.git
                        cd gitops-repo
                        sed -i 's|image: nexus:8082/sample-app:.*|image: ${IMAGE_NAME}:${IMAGE_TAG}|' k8s/deployment.yaml
                        git config user.email "jenkins@ci.local"
                        git config user.name "Jenkins"
                        git diff --quiet || git commit -am "ci: update image to ${IMAGE_TAG}"
                        git push
                    """
                }
            }
        }
    }

    post {
        regression {
            slackSend channel: '#deployments', color: 'danger',
                      message: "NEWLY BROKEN: ${env.JOB_NAME} #${env.BUILD_NUMBER} | <${env.BUILD_URL}|View>"
        }
        fixed {
            slackSend channel: '#deployments', color: 'good',
                      message: "FIXED: ${env.JOB_NAME} #${env.BUILD_NUMBER} | <${env.BUILD_URL}|View>"
        }
        failure {
            slackSend channel: '#deployments', color: 'danger',
                      message: "FAILED: ${env.JOB_NAME} #${env.BUILD_NUMBER} | <${env.BUILD_URL}|View>"
        }
        always {
            cleanWs()   // clean workspace after each build
        }
    }
}
```

## Troubleshooting the Full Pipeline

### Symptom: Pipeline passes all stages but ArgoCD does not deploy
1. Check if the GitOps repo was actually updated: `git log` on the repo
2. Check ArgoCD sync status: `kubectl -n argocd get application sample-app`
3. Check ArgoCD logs: `kubectl -n argocd logs deployment/argocd-application-controller`
4. Manually trigger sync: `argocd app sync sample-app`

### Symptom: Pod deployed but Vault secrets not injected
1. Check pod events: `kubectl describe pod <pod>` — look for Vault Agent init container errors
2. Check init container logs: `kubectl logs <pod> -c vault-agent-init`
3. Verify ServiceAccount: `kubectl get pod <pod> -o jsonpath='{.spec.serviceAccountName}'`
4. Verify Vault role: `kubectl exec -n vault vault-0 -- vault read auth/kubernetes/role/sample-app`

### Symptom: Kyverno blocks ArgoCD deployment
1. ArgoCD sync status shows error — check the error message for the Kyverno rule name
2. Fix the deployment manifest to comply with the policy
3. If the policy is wrong, update it in the `policies/` folder and push to GitOps repo

### Symptom: SonarQube quality gate hangs forever
→ Webhook not configured. See 01_SonarQube/tasks.md — Step 5.

### Symptom: Nexus push fails with 401
→ Insecure registry not configured, or credentials wrong. See 05_Nexus/tasks.md — Common Errors.
